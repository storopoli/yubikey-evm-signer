Notice

WebUSB is unavailable in this browser or context. Use the Local PC/SC Bridge below to connect your YubiKey in any browser.

Browser & Transport Support

Standard Chromium browsers block raw WebUSB access to YubiKey PIV applets twice on regular web pages across all operating systems:

  • Chromium USB Blocklist: usb_blocklist.cc hard-blocks Yubico VID 0x1050 (PIDs 0x0010–0x0410).
  • Protected Smart Card Class: Chromium enforces USB Smart Card class 0x0B (CCID) as a WICG Protected Interface Class on standard https:// and http://localhost pages.

Choose one of the following transports:

  • Local PC/SC Bridge: Recommended — Works across macOS, Linux, and Windows in Chrome, Firefox, Safari, Edge, and Brave. Start it locally with just cli-bridge (or cargo run --example yubikey-cli -p yubikey-evm-signer-core --features pcsc -- bridge), then paste the printed http://127.0.0.1:<port> URL and bearer token below.
  • WebUSB: Experimental — Only works for non-blocklisted CCID tokens or Chromium Isolated Web Apps with unrestricted USB permissions. On Linux, non-root USB access may also require udev rules.

The derived address is keccak256(X ‖ Y)[12..] of the slot's P-256 key. It is not a secp256k1 account: on standard EVM chains nothing can be sent from it and these signatures do not ecrecover to it. Contracts that verify them with P256VERIFY (EIP-7951), such as smart accounts, need the public key above.

Over the Local PC/SC Bridge, management key authentication and key generation require starting the bridge with yubikey-cli bridge --allow-generate (just cli-bridge --allow-generate); otherwise the bridge refuses them (403).
